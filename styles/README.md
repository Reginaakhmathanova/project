В данной папке хранятся CSS файлы проекта.

buttons.css - в этом файле описаны стили для кнопок.

colors.css - в этом файле хранятся все основные цвета проекта, в дальнейшем изменив цвета только в одном файле можно будет поменять весь проект.

fonts.css - в этом файле описаны шрифты.

normalize.css - для унификации стилей в разных браузерах.

styles.css - основные стили проекта.
