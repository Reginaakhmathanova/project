Учиться PRO100

Учиться PRO100 — это веб-страница, предоставляющая платформу для подготовки к экзаменам, таким как ЕГЭ и ОГЭ, а также для изучения других школьных предметов и подготовки к олимпиадам.

Описание

Данный проект представляет собой учебную платформу с удобным интерфейсом, позволяющим:

    Ознакомиться с направлениями подготовки.
    Прочитать отзывы студентов.
    Получить информацию о преподавателях.
    Легко и быстро найти контактные данные.

Структура проекта

Учиться PRO100/

├── css/

├── README.md             # Файл документации

Технологии

Проект использует следующие технологии:

    HTML5 для структуры страницы.
    CSS3 для стилизации и адаптивного дизайна.
    Normalize.css для унификации стилей в разных браузерах.
